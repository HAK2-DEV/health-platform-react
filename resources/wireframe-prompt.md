# 와이어프레임(사이트맵) 생성 요청문

> 아래 내용을 이미지/다이어그램 생성 AI에 그대로 복사해 사용하세요.

---

당신은 UX/정보구조(IA) 다이어그램 디자이너입니다.
아래 설명한 웹앱의 **사이트맵 / 와이어프레임 트리 다이어그램**을 한 장의 이미지로 만들어 주세요.

## 비주얼 스타일 — 반드시 이 스타일을 따를 것

- **톤: 파스텔(부드럽고 밝은 색감)**
  - 배경: 아주 옅은 파스텔(예: #F7F9FC 같은 거의 흰색에 가까운 톤)
  - 상위 계층 박스: 채워진 파스텔 색(민트/세이지 그린, 또는 파스텔 블루 계열)
  - 하위 항목 박스: 흰색 배경 + 옅은 파스텔 테두리(아웃라인)
  - 텍스트: 진한 회색(#3A3A3A)으로 가독성 확보 (파스텔 배경 위에서도 잘 보이게)
  - 연결선: 옅은 파스텔 점선(dashed), 분기 지점에 작은 파스텔 원형 노드
- **레이아웃**: 위에서 아래로 흐르는 트리. 최상단 진입 화면 → 아래로 분기 →
  5개 메인 섹션이 가로로 나란히, 각 섹션 아래로 하위 화면이 세로로 나열
- 좌상단에 제목 **"와이어프레임"** (파스텔 톤의 굵은 글씨)
- 전체적으로 깔끔하고 여백 있는, 부드러운 인포그래픽 느낌

## 이 앱이 무엇인가

**"건강증진 플랫폼"** — 누구나 '건강 운영자'가 되어 직접 건강 프로그램을 만들고,
다른 사람을 참여시켜 함께 건강 습관을 만드는 모바일 웹앱(PWA)입니다.

- **운영자**: 프로그램·미션·퀴즈를 만들고, 참여자의 인증(사진/메모)을 심사하며,
  **참여 현황과 성과를 통계로 한눈에 확인**함
- **참여자**: 프로그램에 참여해 매일 미션을 '인증'하고, 퀴즈를 풀고, 랭킹으로 동기부여
- 핵심 메타포: 물=인증, 햇빛=출석. 꾸준함이 쌓여 자람
- 함께도 좋고 혼자도 좋은, 격려와 도전이 균형 잡힌 건강 습관 도구

## 화면 구조 — 이 계층을 그대로 트리로 그릴 것

### ■ 진입 / 인증 (최상단, 세로로 연결)

```
시작 화면(랜딩)
 └ 로그인 / 회원가입  (소셜 로그인: 카카오·구글·네이버)
 └ 닉네임 설정 (최초 1회)
 └ 약관·개인정보 동의
```

### ■ 위 진입 화면 아래에서 5개 메인 섹션으로 분기 (하단 5탭 네비게이션)

**1) 홈 (대시보드)**
- 오늘의 인증 미션
- 최근 인증 기록
- 참여 중 프로그램 요약

**2) 프로그램**
- 프로그램 목록 (참여/운영 중)
- 프로그램 만들기 (생성 마법사)
- 코드로 참여하기
- 프로그램 상세
  - 개요 / 미션 / 묶음(번들)
  - 미션 인증하기 _(참여자)_
  - 퀴즈 풀기 _(참여자)_
  - 피드 (인증 모아보기·좋아요·댓글)
  - **[운영자] 인증 심사**
  - **[운영자] 게시물·퀴즈 발행**
  - **[운영자] 통계 — 참여 현황·성과 분석 (미션별 / 참여자별 / 퀴즈별)**

**3) 랭킹**
- 프로그램 랭킹
- 게이미피케이션 (정원 / 별자리 / 도감) — **🚧 준비중**

**4) 알림**
- 알림 목록 (심사 결과·댓글·좋아요 등)

**5) 프로필**
- 내 프로필
- 나의 활동 (참여 프로그램·미션·인증 내역)
- 알림 설정
- 계정 설정 (회원 탈퇴 포함)

## 출력

- 위 계층 그대로, 파스텔 톤의 사이트맵 다이어그램 **이미지 한 장**을 생성
- 한국어 라벨 사용
- 5개 메인 섹션은 가로로 나란히, 하위 항목은 그 아래 세로 정렬
- **"게이미피케이션" 항목에는 "준비중" 배지/표시**를 함께 넣어, 아직 출시 전 기능임을 시각적으로 구분
- **운영자 전용 항목**([운영자] 표시)은 일반 항목과 색/아이콘 등으로 살짝 구분되게 표현
