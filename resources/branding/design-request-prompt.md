===== 여기부터 복사 =====

당신은 모바일 헬스케어 제품의 **브랜드 디자이너**입니다. 아래 브리프를 읽고, 요청한 산출물을 제안해 주세요. 먼저 **컨셉을 이해했는지 한 줄 요약**한 뒤 작업해 주세요.

## 1. 제품 한 줄
건강증진담당자(군 보건담당·기업 보건 등)가 **건강 프로그램을 쉽게 만들고 운영**하도록 돕고, 그 힘이 일반 사용자에게까지 퍼지는 **모바일 웹앱(PWA)**입니다. "누구나 건강 운영자가 될 수 있는" 플랫폼입니다.

## 2. 브랜드 컨셉 (이 결을 반드시 지켜주세요)
- **태그라인:** "운영은 쉽게, 건강은 단단하게."
- **존재 이유(가장 깊은 가치):** 건강이라는 *재산*이 흩어지지 않도록 돕는다.
- **핵심 키워드 3:**
  - **쉬움** — 누구나 가볍게 운영 (민주화)
  - **단단함** — 건강은 재산, 작은 투자의 누적·지킴
  - **동행** — 함께도 좋고 혼자도 좋다. 격려와 도전의 균형
- **페르소나 톤:** "따뜻한 동반자 + 친근한 전문 트레이너". 정보는 전문가답게, 격려는 따뜻하게.

## 3. 비주얼 톤앤매너
- 깨끗하고 정돈된(신뢰) + 부드러운 곡선(따뜻). **의료적 차가움 금지, 유치한 캐주얼 금지.**
- 모티프: **함께 자라는 잎/새싹** — 한 뿌리에서 여러 잎이 자라는 형태. **"여러"=다수성/함께**가 핵심. (사람 1명을 그리지 말 것)
- 모던/플랫/심플 일러스트. 과한 그림자·사실적 질감 지양.

## 4. 색 방향 (제안받고 싶음)
현재는 민트/에메랄드 파스텔이 기본인데, **조금 더 트렌디한 방향**도 보고 싶습니다. 아래 4개 방향을 각각 적용한 변주를 만들고, **추천 1안**을 골라 이유를 적어주세요.
1. 에메랄드 리프레시 — 현 톤 + 채도↑ (#059669 / 포인트 #34D399)
2. 딥 틸 + 라임 — 신뢰+활력 (#0F766E / 포인트 #84CC16)
3. 세이지 + 샌드 — 차분·프리미엄 (#5F7A5F / 포인트 #D39A5E / 배경 #F3F0E8)
4. 인디고 나이트 + 민트 — 테크·세련 (#4F46E5 / 포인트 #2DD4BF)

## 5. 요청 산출물
**(A) 앱 아이콘 / 심볼 마크 — [필수, 1순위]**
- "함께 자라는 잎" 컨셉의 심볼.
- **글자/워드마크는 넣지 마세요.** (제품명 미확정 → 심볼만 먼저)
- 다음 변형 제공:
  - 풀컬러(배경 채운 앱 아이콘, iOS/안드로이드용)
  - 단색 1색(앱 헤더·파비콘용)
  - 라이트/다크 배경 모두에서 또렷한지
- **32~48px 썸네일에서도 형태가 뭉개지지 않게** 단순하게. 가장자리에 안전 여백.

**(B) 색 팔레트 제안 — [필수]**
- §4의 방향들로 변주 + 추천 1안. primary / accent / 배경 / 텍스트(잉크) 색 명시.

**(C) 보조 일러스트 스타일 1컷 — [선택]**
- 앱 전반에 쓸 일러스트의 톤을 보여줄 대표 1컷(예: 작은 식물/새싹을 돌보는 따뜻한 장면, 사람 얼굴 클로즈업 X).
- 이후 카테고리 아이콘·빈 화면 일러스트를 같은 스타일로 확장할 예정.

## 6. 반드시 피해야 할 것 (브랜드 금지선)
- Before/After 비교, 체중·체형·외모 강조, 다이어트 강박 뉘앙스 **금지**.
- 사람 1명을 주인공으로 그리지 말 것(다수성·함께가 핵심). 굳이 사람을 넣는다면 익명적·다수.
- 차가운 병원 느낌, 혈압계·약·주사 등 의료기기 모티프 **지양**.
- 지나치게 아동용/장난스러운 톤 **지양**.

## 7. 산출 스펙
- 아이콘 원본: 정사각 1024×1024, 가능하면 **SVG**(없으면 PNG 투명배경).
- 색·여백 값(HEX)과 함께 제공. 단색 버전 별도.
- 각 시안에 **왜 이 컨셉인지 1~2줄 설명**.

## 8. 레퍼런스(형태 가이드)
- 줄기 하나에서 **잎 3장**이 약간 다른 높이로 함께 솟는 실루엣 → "함께 자란다"를 직관적으로.
- Lucide 아이콘의 'Sprout'를 더 풍성하게(잎 2→3장) 발전시킨 느낌.

먼저 컨셉 이해를 한 줄로 확인하고, (A)→(B)→(C) 순서로 제안해 주세요.
