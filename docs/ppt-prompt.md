# 왜 만들었나 — 본인 배경

저는 **군에서 건강증진 담당 업무**를 했습니다.
매번 같은 고민이 있었어요:
- 참여자 인증을 어떻게 받지? 종이? 카톡 인증샷?

**4가지 문제** — 참여자 관리 / 동기 부여 부족 / 데이터 없음 / 운영자 번아웃.

# 핵심 기능 (PPT 분량 1순위)

## 기능 1 — 프로그램 마법사

4 단계로 프로그램 4분 만에 발행. 임시 저장 가능:
1. **기본 정보** — 이름·기간·카테고리
2. **분위기 정하기** — 커뮤니티 피드 / 랭킹·성장 동기 / 하위 옵션
3. **참여 조건** — 공개/승인 후/초대코드 + 최대 인원
4. **요약 + 게시**

날짜 입력 시 종료일 달력 자동 펼침 등 모바일 UX 다듬음.

## 기능 2 — 미션 라이브러리 (43개 + AI 일러스트)

운영자가 묶음 통째로 추가. **7 카테고리 × 총 43 미션**:
- 🚶 WALKING (10) — 걷기·러닝·스트레칭·운동
- 🥗 DIET (9) — 식단·수분·단백질·채소
- 📚 ETC (7) — 아침루틴·독서·취미
- 🧘 MINDCARE (6) — 명상·감사 일기·스트레스 해소
- 🌙 SLEEP (5) — 수면 회복·잠자기 전 루틴
- 🤝 EMPATHY (4) — 공감·가족·친절
- 🚭 NO_SMOKING (2) — 금연

각 미션마다 **AI 일러스트 아이콘 사전 제작** (43장 모두 누끼 처리).
시각적 일관성 + 인지 부담 ↓.

## 기능 3 — 인증 흐름

참여자가 미션 인증하는 방법:
- 🖼 **사진** 업로드 (운동·식단)
- 📊 **숫자** 기록 (걸음 수·러닝 km·수면 시간)
- 💬 **소감** 한 줄 (오늘의 감사·컨디션)

자동 승인 또는 운영자 심사 선택. 인증마다 점수 적립.
인증 페이지: 큰 미션 일러스트가 상단 풀블리드 + 격려 카피.

## 기능 4 — 격려 시스템 (게이미피케이션)

### 🏆 랭킹 (현재 베타)
- 포디움 (1·2·3등 시각 강조 — 올림픽 시상대)
- 본인 14일 점수 sparkline (꾸준함 시각화)
- 기간 필터 (전체 / 최근 7일 / 최근 30일)
- "내 위치로" floating 버튼

### 🌱 성장 (곧 출시 — 코드 완성, 베타엔 비활성)
- **정원**: 본인 4×4 정원에 씨앗 심기, 16종 꽃 풀 (랜덤 추첨)
- 5단계 성장 — 만개에서 정체 공개 + 도감에 추가
- 식물 클릭 시 물·햇빛 주는 모션 (물방울 + 햇빛 펄스)
- **별자리**: 본인 은하에 별 5개 점등 + 연결선 (12개 별자리 풀)
- **운영자가 프로그램별로 선택** — 랭킹 vs 성장

비전: "1·2·3등이 아닌, 각자의 정원·각자의 별자리."

## 기능 5 — 운영자 도구 (데이터로 보는 인사이트)

- **3대 지표**: 참여율 / 미션 다양성 / 최근 7일 꾸준함
- **7일 추세 sparkline** + 지난주 vs 이번주 비교
- **시간대 패턴**: KST 0-23시 막대 + 4구간 분포 (새벽·아침·낮·저녁)
- **미션별 시간대 sparkline + peak 시간** — "산책은 아침, 명상은 저녁"
- **참여자 상태 분포** (활발·보통·휴면) — 클릭하면 필터 진입
- **휴면 참가자 추적** — "누구에게 손 내밀까"
- **주간 하이라이트** — AI 자동 추출, 따뜻한 톤 카피

데이터로 「감」 이 아닌 「근거」 로 운영.

## 기능 6 — 마일스톤 토스트

인증 후 자동 감지:
- 「🔥 7일 연속 달성!」
- 「🎯 누적 50건 인증 달성!」
- 「🌸 만개! 식물의 정체가 공개됐어요」

업적 잠금 해제 효과 — 사용자 즐거움.

## 기능 7 — 커뮤니티 (옵션)

운영자가 선택 시 활성. 사진 피드 + 좋아요 + 댓글.
참여자끼리 응원 + 격려.

## 기능 8 — 진행도 시각화

프로그램 진행도 막대 색 변화:
- < 70%: 카테고리 색 (평소)
- 70-89%: amber + 「⏳ 마무리 단계」
- 90-99%: rose + 「🔥 마무리 임박」
- = 100%: gray + 「🏁 종료」

"끝까지 화이팅" 응원의 시각화.

## 기능 9 — 소셜 로그인

Kakao + Google (모두 동작 확인).
OAuth 콜백 후 닉네임 설정 자동 이동.

## 기능 10 — PWA

모바일 앱 설치 가능 + 오프라인 캐싱 (Service Worker).
Capacitor 로 네이티브 출시 예정 (앱스토어 / Google Play).

## 추가 요청
