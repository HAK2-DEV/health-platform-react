운영은 쉽게, 건강은 단단하게. 미션·퀴즈·랭킹으로 함께 만드는 건강 습관 플랫폼.
```

**자세한 설명** (≤4000자)
```
도담은 "누구나 건강 운영자가 될 수 있도록" 돕는 도구예요.
혼자도 좋고, 함께라면 더 좋습니다. 격려와 도전의 조화로, 건강이라는 재산을 흩어버리지 않도록.

■ 운영자라면
- 클릭 몇 번으로 나만의 건강 챌린지를 만들고 운영해요.
- 미션·퀴즈·커뮤니티·랭킹·팀을 원하는 대로 켜고 끕니다.
- 참여자 현황·인증 관리·종료 리포트까지 한 곳에서.

■ 참여자라면
- 매일 미션을 인증하며 작은 습관을 단단하게 쌓아요.
- 건강 퀴즈로 지식을 채우고, 커뮤니티에서 서로 응원해요.
- 내 활동 추이와 연속 기록으로 꾸준함을 확인해요.

■ 이런 분께
- 우리 모임·동아리·팀의 건강 챌린지를 운영하고 싶은 분
- 혼자서도 습관을 꾸준히 만들고 싶은 분
- 보건소·기업·학교 등에서 건강증진 프로그램을 운영하는 분

■ 건강 기능 (건강 앱 선언과 1:1 대응 — 활동 및 피트니스 · 수면 관리 · 스트레스 관리)
- 운동·달리기·수면·마음관리 카테고리의 미션을 만들고 사진·메모로 인증해요.
- 금연 챌린지: 연속 금연 일수와 일반적인 회복 단계 안내, 기분 체크로 오늘의 마음을 기록해요.
- 운영자가 만든 설문으로 프로그램 전후 변화를 함께 살펴봐요.
- 걸음 수·위치는 수집하지 않아요.

■ 로그인
- 이메일 또는 Google 계정으로 로그인해요.

지금 도담과 함께, 건강한 습관으로 더 나은 내일을 만들어요.

도담은 의료기기가 아니며, 질병의 진단·치료·치유·예방을 목적으로 하지 않습니다. 앱이 제공하는 건강 정보는 일반적인 안내이며 개인차가 있습니다. 건강에 관한 결정은 의사 등 전문가와 상담하세요.

## 2. 데이터 보안(Data safety) 폼 답변 초안

> Play Console → 앱 콘텐츠 → 데이터 보안. 코드·프로드 DB 로 확정한 답(2026-09-14). 개인정보처리방침 v1.1 과 1:1.

**공통 답변**: 수집 **예** · 전송 중 암호화 **예** · 삭제 요청 방법 제공 **예**(URL `https://healthplatform-pi.vercel.app/account-deletion.html`) · 제3자 **공유 없음**(Supabase·Vercel·Sentry·Firebase 는 «서비스 제공업체» 전송이라 공유 아님).

| 카테고리 › 항목 | 내용 | 필수/선택 | 목적 | 연결 |
|---|---|---|---|---|
| 개인 정보 › 이름·이메일·사용자 ID | 닉네임·이메일·계정 ID | 필수 | 앱 기능·계정 관리 | 연결됨 |
| 사진 및 동영상 › 사진 | 인증·게시글·프로필 사진 | 선택 | 앱 기능 | 연결됨 |
| 건강 및 피트니스 › 건강 정보 | 기분 체크·금연 기록·설문 응답·미션 수치 | 선택 | 앱 기능 | 연결됨 |
| 메시지 › 기타 앱 내 메시지 | 응원·댓글·1:1 문의 | 선택 | 앱 기능 | 연결됨 |
| 앱 활동 › 앱 상호작용·UGC | 화면 통계(회원 ID 포함)·게시글 | 필수/선택 | 분석·앱 기능 | 연결됨 |
| 앱 정보 및 성능 › 비정상 종료 로그·진단 | Sentry 브라우저 SDK(PII 없음, 성능 10% 샘플) | 필수 | 분석 | 연결 안 됨 |
| 기기 또는 기타 ID | FCM 등록 토큰·Firebase 설치 ID | 필수(알림 켤 때) | 앱 기능 | 연결됨 |

**신고하지 않음**: 위치 · 걸음 수(피트니스 정보 — STEPS_ENABLED=false, 매니페스트 health 권한 0개) · 연락처 · 광고 ID. Sentry 는 기기 ID 를 만들지 않는다(브라우저 SDK) — 기기 ID 항목은 FCM 때문.

**건강 앱 선언** (정책 › 앱 콘텐츠 › 건강 앱 — 권한 지웠어도 전 앱 필수, 비공개 테스트 포함): ✅ 활동 및 피트니스 · ✅ 수면 관리 · ✅ 스트레스 관리. ❌ 영양/체중 관리(식단 마법사 제외, 체중 0건) ❌ 의료 계열 전부(개인 계정 ↔ 조직 계정 요구 충돌). 금연은 공식 카테고리 없음 → 자유서술 칸 있으면 "금연 습관 챌린지(연속 금연 일수·회복 단계 안내·기분 체크)".

## 3. 업로드 키스토어 + 서명 (나중에 — 계정 전이라도 가능)

Play는 **Play App Signing**을 쓴다: 앱 서명 키는 Google이 보관, 우리는 **업로드 키**만 관리.
업로드 키 분실해도 재설정 가능(앱 서명 키는 Google이 가짐)이라 예전만큼 치명적이진 않지만, 백업 필수.

### 3-1. 업로드 키스토어 생성 (예시 — 비밀번호는 본인이 정함)
```powershell
$env:JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-21.0.12.8-hotspot"
& "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -v `
  -keystore dodam-upload.jks -alias dodam-upload `
  -keyalg RSA -keysize 2048 -validity 10000
# → 비밀번호(스토어/키), 이름/조직 입력. jks 파일 + 비번 안전 보관(비밀번호 관리자/오프라인 백업).
```
- `dodam-upload.jks`는 **레포에 커밋 금지**(.gitignore). 안전한 곳 2벌 백업.

### 3-2. Gradle 서명 설정 (키스토어 만든 뒤)
`android/keystore.properties` (gitignore):
```
storeFile=../../dodam-upload.jks
storePassword=****
keyAlias=dodam-upload
keyPassword=****
```
`android/app/build.gradle`의 `buildTypes.release`에 signingConfig 연결 (그때 코드로 추가).

### 3-3. 릴리스 AAB 빌드
```powershell
npm run build; npx cap sync android
cd android; .\gradlew.bat bundleRelease
# 산출물: android/app/build/outputs/bundle/release/app-release.aab  ← Play 업로드용
```

## 4. Play Console 흐름 (계정 생긴 뒤)

1. **개발자 등록**: play.google.com/console, $25, 신원확인(개인=신분증, 며칠 소요).
   - ⚠️ **개인 계정(2023-11 이후 생성)**: 프로덕션 전에 **비공개 테스트 12명 이상 × 연속 14일** 필수(정책 원문 answer/14151465).
     → 옵트아웃은 «개인 단위»로만 제외됨(전체 리셋·거절 후 재시작 조항 없음). 이탈 여유로 15명 모집. 사업자등록 후 **조직 계정**이면 요건 완화 가능.
2. **앱 만들기**: 이름 "도담", 무료, 앱.
3. **설정 완료**(대시보드 체크리스트): 개인정보처리방침 URL, 앱 액세스(로그인 필요 시 테스트 계정 제공), 광고 없음, 콘텐츠 등급 설문, 타겟층(성인/전연령), 데이터 보안(위 2), 정부앱 아님.
4. **스토어 등록정보**: 위 1의 텍스트 + 아이콘(512) + 피처그래픽(1024×500) + 스크린샷(2~8장).
5. **비공개 테스트 트랙**: AAB 업로드 → 테스터 목록(이메일 12명 이상) → 링크 배포 → 14일 운영(중간 릴리스 1~2회 + 피드백 기록 → 프로덕션 액세스 신청서 재료).
6. **프로덕션 신청**: 14일 충족 후 프로덕션 출시 신청 → 검토(며칠) → 출시.
