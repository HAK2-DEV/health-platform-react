# UI/UX 전면 개편 기획서 (Redesign Brief)

> **버전**: v0.2 (2026-06-16, 컨셉 확정)
> **작성 목적**: 본인(운영자/아키텍트)이 결정하기 위한 토대. 확정이 아니라 **구체화된 제안 + 결정 포인트**.
> **기준점(북극성)**: "누구나 건강 운영자가 될 수 있도록 돕는 도구. 함께도 좋고 혼자도 좋다. 격려와 도전의 조화로, 건강이라는 재산을 흩어버리지 않도록."
> **포지셔닝**: C — **담당자가 코어/입구, 거기서 보편으로 확산** (product-led growth).
> **태그라인(확정)**: **"운영은 쉽게, 건강은 단단하게."**
> **세 키워드(확정)**: **쉬움 · 단단함 · 동행** — 모든 화면/카피/기능 결정의 잣대.

이 문서는 본인이 던진 6개 항목(기획의도 / 해결방안 / 키워드·비전 / 네이밍·아이콘·로고 / 와이어프레임 / 홈화면)을 순서대로 구체화한다. **"🟩 결정 필요"** 표시가 붙은 곳은 본인이 골라야 진행되는 지점이다.

---

## 1. 기획의도 (Why)

### 1.1 우리가 푸는 문제
- **건강증진담당자**: 본업(군의관·보건담당 등)에 겸임으로 밀려, 양질의 프로그램을 만들 시간이 없다. → "도구만 있으면 본업에 집중하면서도 좋은 프로그램을 줄 수 있다."
- **참여자**: 혼자 하면 작심삼일, 함께 하면 비교·압박. 둘 다 지친다. → "내 페이스로, 그러나 혼자 아닌 느낌."
- **건강 인식**: 건강은 재산인데 우리는 소홀하다. 외형(체중·성형)에 집착하고 진짜 건강을 놓친다.

### 1.2 우리가 의도적으로 *안* 하는 것 (경계선)
- Before/After 사진 비교, 다이어트 강박, 외모·체중 강조 미션 ❌
- 비교성 압박 카피("친구가 당신보다 많이 했어요") ❌
- 사용자(참여자)에게 광고·판매 ❌ (수익은 결정권자/기관에게서)
- 잘못된 건강 신념 주입 ❌

### 1.3 개편이 지금 필요한 이유 (현 UI의 한계)
- **홈이 세로로 길다.** 현재 홈 = 통계4카드 → 참여 중인 프로그램 → 오늘의 미션 → 운영중인 프로그램, **4개 섹션이 수직 적재** → 핵심(오늘 뭘 해야 하나)이 한눈에 안 들어오고 스크롤을 강요한다.
- **정체성이 화면에 안 드러난다.** "건강 운영 도구 / 함께 가꾸는 여정"이라는 비전이 현재 UI에선 일반적인 "건강 앱"과 구분이 안 된다.
- **게이미피케이션(정원·별자리)이 메인에 없다.** 가장 강한 차별점인데 프로그램 상세 깊숙이 숨어 있다.
- **브랜드(이름·로고)가 placeholder.** 헤더에 `🌿 Health-Platform` 임시 텍스트.

## 2. 해결방안 (What)

| 문제 | 해결 방향 |
| --- | --- |
| 홈 스크롤 과다 | **"오늘 중심" 단일 화면** — 한 화면에 오늘 할 일 + 내 성장 + 빠른 진입만. 목록류는 가로 캐러셀/네비로 이동 (§6). |
| 차별점 안 보임 | 홈 상단에 **성장 위젯(정원/별자리)** 상시 노출 — "물=인증, 햇빛=출석" 메타포 시각화. |
| 정체성 흐림 | **네이밍·로고·아이콘 확정**(§4) + 따뜻한 전문가 톤 카피 시스템. |
| 혼자/함께 균형 | 솔로 모드 정당화 카피 + 진행률 비공개 옵션을 UI 1급 시민으로. |
| 운영자 진입장벽 | "내가 운영하기" 흐름·복제·라이브러리를 홈에서 한 번에 닿게. |

**개편 범위**: 디자인 토큰은 이미 잡혀 있으므로(민트/에메랄드, rounded-2xl, Pretendard) **레이아웃·정보구조(IA)·브랜드**가 핵심. 색·컴포넌트 프리미티브는 유지·확장한다.

## 3. 키워드 및 비전 (Soul) — ✅ 확정 (2026-06-16)

### 3.1 컨셉 구조 (골든 서클)
표면과 심층은 경쟁이 아니라 **층(layer)**이다. 밖으로는 ①로 말 걸고, 안으로는 ③이 끌고 간다. ②가 다리.

| 층 | 역할 | 내용 |
| --- | --- | --- |
| **WHY (가장 깊음)** | 존재 이유 · 내부 북극성 | ③ **건강이라는 재산이 흩어지지 않도록** |
| **HOW (작동 원리)** | 어떻게 이루나 | ② 누구나 운영자가 되어 (민주화·확산) |
| **WHAT (표면)** | 먼저 내거는 약속 | ① **담당자에게 좋은 프로그램 만들 시간을** |

- **미션 (내부 북극성):** "건강이라는 재산이 흩어지지 않도록 돕는다."
- **태그라인 (외부 한 줄):** **"운영은 쉽게, 건강은 단단하게."**
  - *쉽게* = 담당자 약속(①), *단단하게* = 흩어지지 않는 재산(③). 한 줄에 두 층.

### 3.1.1 핵심 키워드 3 (결정 잣대)
| 키워드 | 의미 | 잣대 |
| --- | --- | --- |
| **쉬움**| 담당자도, 누구나도 가볍게 운영 (≈민주화) | "운영을 더 쉽게 만드나?" |
| **단단함** | 건강=재산, 작은 투자의 누적·지킴 (≈재산) | "건강을 더 단단하게 쌓나?" |
| **동행** | 함께도 혼자도 — 격려·도전 균형 (≈균형) | "동행을 살리나, 압박을 주나?" |

### 3.2 무드보드 / 톤
- **시각**: 깨끗·정돈(신뢰) + 부드러운 곡선(따뜻). 의료적 차가움 ❌, 가벼운 캐주얼 ❌.
- **색 — ✅ 확정 "Emerald Refresh" (2026-06-16):**
  - Primary `#059669` · Accent `#34D399` · Background `#ECFDF5` · Ink `#073B33`
  - (딥틸+라임 / 세이지+샌드 / 인디고나이트+민트 등 대안은 미채택)
- **아이콘 — ✅ 방향 확정:** "함께 자라는 잎" 새싹 심볼(흰 잎 다수 + 에메랄드 그라데이션 배경). 외부 AI 생성 시안 채택.
- **말투**: "따뜻한 동반자 + 친근한 전문 트레이너". 정보는 전문가, 격려는 따뜻하게.
- **모티프**: 함께 자라는 새싹 / 정원 / 별자리. **한 명(개인)이 아니라 다수성**을 암시.

## 4. 네이밍 · 아이콘 · 로고 (Brand)

### 4.1 네이밍 후보  🟩 결정 필요 (보류 중)
> **방향 갱신(2026-06-16)**: "정원/가꿈/건강정원" 계열은 제외. 본인 정체성("담당자가 프로그램을 운영·개선하고 사용자 건강을 돕는 플랫폼")에 맞춰 **연결·동행·매일의 누적** 결로 재탐색.

| 후보 | 의미 | 키워드 적합 |
| --- | --- | --- |
| **동행** | 함께 가는 길 — 함께도 혼자도. 따뜻한 동반자. | 동행 ◎ |
| **이음** | 잇다 — 담당자와 참여자를 연결. | 쉬움(민주화)·동행 ○ |
| **온하루** | 따뜻한(溫) 매일의 누적. | 단단함(재산) ○ |
| **곁** | 곁에 있다 — 짧고 따뜻한 동반자. | 동행 ○ |

> 비고: 이름은 **이미지/아이콘 시안을 받아본 뒤 확정**하기로 함(심볼 먼저, 워드마크 나중). "핏(fit)"류는 외형·체중 강조 금지 원칙과 충돌하여 제외.

### 4.2 아이콘 (앱 아이콘)
- 원칙(북극성): **다수성 + 신뢰감 + 따뜻함** 동시 충족. 사람 1명 ❌.
- 이미 만든 시안: `resources/icon-concepts/` (leaf / heart-leaf / sprout) — 이 중 **여러 잎이 함께 자라는** 모티프를 발전.
- 제안 방향 3안  🟩 결정 필요:
  1. **두세 개의 잎이 한 줄기에서** 자라는 실루엣(함께 성장) — 민트 그라데이션.
  2. **손바닥 위 새싹**(돌봄·운영) — 따뜻한 강조색 살짝.
  3. **새싹 + 작은 별** 결합(정원·별자리 두 트랙 암시).

### 4.3 로고 (워드마크)
- 한글 워드마크 + 심볼(아이콘) 조합. 라운드/소프트한 산세리프(현 Pretendard와 일관).
- 라이트/다크 + 단색(앱 헤더용) 변형 필요.
- 현재 헤더의 `🌿 Health-Platform` 임시 표기를 확정 워드마크로 교체.

## 5. 와이어프레임 (IA & Flows)

### 5.1 정보 구조 (5탭 유지, 역할 재정의)
```
[홈]        오늘 중심 — 할 일 + 내 성장 + 빠른 진입 (스크롤 최소)
[프로그램]   둘러보기 + 운영중/참여중 목록 + 생성(FAB)
[랭킹/성장]  랭킹 · 정원 · 별자리 (프로그램 트랙에 따라)
[알림]       활동 피드백
[프로필]     나 · 운영자 가이드 · 설정
```
> 변경 포인트: **목록(운영중/참여중 전체)은 홈에서 [프로그램] 탭으로 이동**. 홈은 "지금 당장"만.

### 5.2 핵심 플로우 (변동 없음, 참고)
- 운영: 마법사 4단계(+게이미피케이션 트랙) → 미션/퀴즈(라이브러리) → 심사 → 통계
- 참여: 둘러보기/초대 → 참여 → 오늘의 미션 인증(입력별 점수) → 성장/랭킹 반영 → 피드

### 5.3 화면별 와이어프레임은 §6(홈)부터 우선 확정 후, 동일 패턴으로 프로그램/상세로 확장한다.

## 6. 홈화면 — "한 화면 + 네비게이션"  ⭐ 핵심

### 6.1 목표
- **스크롤 없이(또는 1스와이프 내)** "오늘 뭘 하면 되는지 + 내가 얼마나 자랐는지"가 보인다.
- 목록·통계 상세는 **가로 캐러셀 / 탭 / 네비**로 접어 둔다 (수직 적재 제거).

### 6.2 현재(문제) vs 제안

**현재 (세로 4섹션 적재 → 길다)**
```
인사 + 로고 + 날짜
[통계 4카드]
[참여 중인 프로그램]  (2개 + 전체보기)
[오늘의 미션]        (2개 + 전체보기)
[운영중인 프로그램]   (2개 + 전체보기)
→ 스크롤 다수
```

**제안 A — "오늘 중심 + 성장 위젯" (권장)**
```
┌──────────────────────────────────────┐
│ 가꿈🌿            오늘 6/16 (월)   🔔  │  ← 컴팩트 헤더(로고+날짜+알림)
│                                        │
│ ┌── 내 성장 ───────────────┐  ← 상시  │
│ │  🌷 4단계  물 ▓▓▓▓░ 햇빛 ▓▓▓░ │  정원/별자리 위젯(탭 전환)
│ │  "오늘 1개만 더 인증하면 만개!" │      │
│ └──────────────────────────┘         │
│                                        │
│ 오늘의 미션  (2/5 완료)   ⌄전체        │  ← 오늘 할 일 = 1순위
│ ┌────────────┐┌────────────┐  →      │  가로 캐러셀(스와이프)
│ │🏃 걷기 +7P  ││🥗 식단 +10P││  ...    │
│ │ [인증]      ││ ✓완료      ││        │
│ └────────────┘└────────────┘         │
│                                        │
│ 빠른 진입  ▸참여중 3 ▸운영중 1 ▸123P  │  ← 통계를 칩/숏컷으로 압축
└──────────────────────────────────────┘
   [홈] [프로그램] [성장] [알림] [프로필]   ← 하단 네비
```
- **성장 위젯 상시 노출** = 차별점을 메인으로. (랭킹 트랙이면 "내 순위" 미니, 정원/별자리면 단계 시각화)
- **오늘의 미션 = 가로 캐러셀** → 세로로 안 쌓임. "2/5 완료" 진행 표시.
- **통계 4카드 → 빠른 진입 칩** 한 줄. 탭하면 해당 목록(프로그램 탭)으로.
- 운영중/참여중 **목록 전체는 홈에서 제거** → [프로그램] 탭.

**제안 B — "세그먼트 전환"**
```
헤더 + 성장 위젯
[ 오늘 | 내 프로그램 | 운영 ]   ← 세그먼트 토글(한 화면 안에서 전환)
 └ 선택된 세그먼트만 표시 → 항상 1뷰 높이
```

**제안 C — "현 구조 압축"** (가장 보수적)
```
통계 → 캐러셀화, 각 목록 2개→1개 + 가로 스크롤. 구조는 유지하되 높이만 축소.
```

🟩 **결정 필요**: A(권장) / B / C 중 방향. (A는 차별점·스크롤 모두 해결, 구현량 중간)

### 6.3 제안 A 상세 컴포넌트
| 영역 | 내용 | 데이터 매핑(기존) |
| --- | --- | --- |
| 컴팩트 헤더 | 로고(확정 워드마크) + 날짜 + 알림벨(뱃지) | `unreadNotifCount`, `formatTodayKstWithWeekday` |
| 성장 위젯 | 단계/물/햇빛 또는 내 순위. 프로그램 1개 선택(칩) | `gamification_type`, 물·햇빛 계산(`lib/gamification`) |
| 오늘의 미션 캐러셀 | 가로 스와이프 카드 + "n/m 완료" | `todayMissions`, `todayCounts` |
| 빠른 진입 칩 | 참여중·운영중·누적P 숏컷 | `runningCount`, `myPrograms.length`, `totalPoints` |

> 솔로 사용자: 성장 위젯 카피를 "오늘은 혼자만의 시간이에요"처럼. 비교형 문구·랭킹 강조 자동 회피(비공개 옵션 존중).

## 7. 결정 포인트 요약 (본인이 고를 것)
1. **태그라인** (§3.1): A / B / C / D 조합
2. **앱 이름** (§4.1): 가꿈 / 살림 / 그 외
